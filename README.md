# End-to-End Forest Fire Weather Index (FWI) Prediction using Machine Learning

## 📌 Project Overview

This project is a **Machine Learning-based web application** that predicts the **Fire Weather Index (FWI)** based on environmental and meteorological conditions.

The goal is to help in **early detection of fire risk**, enabling better decision-making for forest management and disaster prevention.

---

## 🚀 Features

* 📊 Predicts Fire Weather Index using ML model
* 🌡️ Takes real-time environmental inputs
* 🧠 Trained regression model for prediction
* 🌐 Web-based interface using Flask
* 📈 Data preprocessing & feature scaling
* 📉 Model evaluation using performance metrics

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/fwi-prediction-ml.git
cd fwi-prediction-ml
```

### 2️⃣ Create virtual environment (optional but recommended)

```
python -m venv venv
source venv/bin/activate   # For Linux/Mac
venv\Scripts\activate      # For Windows
```

### 3️⃣ Install dependencies

```
pip install -r requirements.txt
```

### 4️⃣ Run the application

```
python app.py
```

### 5️⃣ Open in browser

```
http://127.0.0.1:5000/
```
